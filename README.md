# 🤖 ربات فشرده‌سازی و استخراج فایل تلگرام

یک ربات تلگرامی قدرتمند برای فشرده‌سازی و استخراج فایل‌های ZIP و RAR

## ✨ امکانات

- 📦 فشرده‌سازی چندین فایل به یک فایل ZIP
- 📂 استخراج فایل‌های ZIP و RAR
- 💾 پشتیبانی از فایل‌های تا 2GB
- 🚀 رابط کاربری فارسی و ساده
- ⚡ پردازش سریع و بهینه

## 🎯 دستورات ربات

- `/start` - شروع و نمایش منوی اصلی
- `/compress` - شروع فشرده‌سازی فایل‌ها
- `/extract` - استخراج فایل ZIP/RAR
- `/cancel` - لغو عملیات جاری
- `/help` - نمایش راهنما

## 🚀 نصب و راه‌اندازی

### 1. ساخت ربات در تلگرام

1. به [@BotFather](https://t.me/BotFather) در تلگرام پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نام و username برای ربات انتخاب کنید
4. توکن ربات را کپی کنید

### 2. دیپلوی روی Railway

#### روش اول: از طریق GitHub

1. این پروژه را Fork کنید
2. به [Railway.app](https://railway.app) بروید
3. روی "New Project" کلیک کنید
4. "Deploy from GitHub repo" را انتخاب کنید
5. ریپوزیتوری خود را انتخاب کنید
6. در قسمت Variables، متغیر زیر را اضافه کنید:
   ```
   BOT_TOKEN=توکن_ربات_شما
   ```
7. دیپلوی خودکار شروع می‌شود!

#### روش دوم: با Railway CLI

```bash
# نصب Railway CLI
npm i -g @railway/cli

# لاگین
railway login

# ایجاد پروژه جدید
railway init

# اضافه کردن متغیر محیطی
railway variables set BOT_TOKEN=توکن_ربات_شما

# دیپلوی
railway up
```

### 3. اجرای محلی (برای تست)

```bash
# کلون کردن پروژه
git clone <repository-url>
cd telegram-compress-bot

# نصب dependencies
pip install -r requirements.txt

# ایجاد فایل .env
cp .env.example .env
# توکن ربات را در .env وارد کنید

# اجرای ربات
export BOT_TOKEN=your_token_here
python bot.py
```

## 📖 نحوه استفاده

### فشرده‌سازی فایل‌ها

1. دستور `/compress` را به ربات ارسال کنید
2. فایل‌هایی که می‌خواهید فشرده کنید را یکی یکی ارسال کنید
3. روی دکمه "✅ تموم شد - فشرده‌سازی" کلیک کنید
4. ربات یک فایل ZIP حاوی همه فایل‌ها را برای شما می‌فرستد

### استخراج فایل

1. دستور `/extract` را ارسال کنید
2. فایل ZIP یا RAR خود را بفرستید
3. ربات تمام فایل‌های داخل آن را استخراج و برای شما ارسال می‌کند

## 🔧 تنظیمات پیشرفته

### محدودیت حجم فایل

به صورت پیش‌فرض، حداکثر حجم فایل 2GB است. برای تغییر آن، در فایل `bot.py`:

```python
MAX_FILE_SIZE = 2 * 1024 * 1024 * 1024  # 2GB
```

### محدودیت تعداد فایل‌های استخراج شده

برای تغییر حداکثر تعداد فایل‌هایی که در استخراج ارسال می‌شوند:

```python
for file_path in extracted_files[:20]:  # تغییر عدد 20
```

## 💡 نکات مهم

- Railway در پلن رایگان محدودیت زمانی دارد (500 ساعت در ماه)
- برای فایل‌های بسیار بزرگ، ممکن است زمان بیشتری لازم باشد
- فایل‌های موقت بعد از هر عملیات پاک می‌شوند
- حداکثر 20 فایل در استخراج ارسال می‌شود (برای جلوگیری از اسپم)

## 🐛 عیب‌یابی

### ربات شروع نمی‌شود

- مطمئن شوید `BOT_TOKEN` به درستی تنظیم شده است
- توکن را از BotFather دوباره بگیرید

### خطای "File too large"

- حجم فایل بیش از 2GB است
- می‌توانید `MAX_FILE_SIZE` را تغییر دهید

### خطای استخراج RAR

- مطمئن شوید `unrar` نصب شده است (در Dockerfile موجود است)
